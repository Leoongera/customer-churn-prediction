# Customer Churn Prediction (Machine Learning)
Predicting customer churn using machine learning to identify at-risk customers and improve retention strategies.

## Overview
This project builds a machine learning model to predict customer churn using a real-world telecom dataset. The goal is to identify customers at risk of leaving and provide insights that can help businesses improve retention strategies.

---

## What I Did
- Cleaned and preprocessed a real-world customer dataset
- Handled missing values and converted data types for analysis
- Encoded categorical variables for machine learning
- Split data into training and testing sets
- Built a Logistic Regression model to predict churn
- Evaluated model performance using accuracy and classification metrics

---

## Tools Used
- Python  
- Pandas  
- scikit-learn  

---

## Model Performance
- Achieved strong predictive performance using Logistic Regression
- Evaluated using:
  - Accuracy score
  - Precision, Recall, and F1-score

---

## Key Insights
- Certain customer features strongly influence churn likelihood
- Churn is not random — it can be predicted from behavior patterns
- Machine learning can help businesses proactively retain customers

---

## Business Impact
- Companies can identify at-risk customers early
- Enables targeted retention strategies (offers, support, engagement)
- Reduces revenue loss from customer churn
